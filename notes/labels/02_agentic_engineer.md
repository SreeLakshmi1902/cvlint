
**Agentic Engineer**

**Permanent | C# / .NET | Azure | GitHub Copilot**

Build agents that can do something useful. Give them the tools to act, the context to make decisions and the engineering foundations to work reliably.

Umbrella Club is partnering with a growing Microsoft partner looking for an **Agentic Engineer** to help bring AI into enterprise software and the way engineering teams build it.

You'll join a team working across Microsoft cloud technologies, combining hands-on .NET development with agent design and AI-assisted engineering. There's room to experiment, influence technical direction and share what you learn with other engineers.

**What you'll build**

You'll develop agents that connect to business systems, call APIs and complete tasks across enterprise workflows. You'll make decisions about tools, context, orchestration and when a person needs to step in.

Alongside that, you'll build the C#/.NET services and Azure integrations that support those agents, and use GitHub Copilot to help take work from an idea through implementation, testing and release.

**Your work will include:**

* Building agents with tool calling, context management and clear permissions.
* Developing APIs, services and integrations using C#, modern .NET and Azure.
* Testing agent behaviour and handling failed tool calls, unexpected outputs and incomplete tasks.
* Using GitHub and Copilot to develop, refactor, test and review software.
* Helping the team develop repeatable practices for agent engineering.
* Sharing ideas, reviewing code and mentoring other engineers.

**What you'll bring**

You're an experienced software engineer who has started putting agents to work. You can explain what you built, the decisions you made and what you changed when it didn't behave as expected.

We're looking for:

* Substantial commercial experience with **C# and modern .NET**, including enterprise applications and APIs.
* Practical experience **building AI agents or agentic workflows**, independently or as part of a team.
* An understanding of how agents use tools, manage context and interact with external systems.
* Hands-on experience with **GitHub and GitHub Copilot**.
* Experience building and deploying applications on **Microsoft Azure**.
* Sound engineering judgement around testing, security, maintainability and production support.
* Curiosity, clear communication and a willingness to work through new problems with others.

Experience with Microsoft Foundry, Azure OpenAI, MCP, RAG or agent frameworks would be valuable.
